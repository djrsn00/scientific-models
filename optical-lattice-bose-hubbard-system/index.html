Equations & model scope READ

The displayed 7 × 7 × 7 array is a window into a homogeneous cubic bulk model with six neighbors per site. It is not a finite lattice calculation with open boundaries.

A zero-temperature single-site Gutzwiller calculation gives P(n), ⟨n⟩, Δn, and ψ = ⟨a⟩ in the occupation basis n = 0…12. The basis-tail weight and self-consistency residual are reported above.

(Δn) 2 = ⟨n2⟩ − ⟨n⟩ 2

The parameter ramp visits equilibrium approximations. It does not solve real-time loading, heating, or many-body transition dynamics. The homogeneous equilibrium state carries no net bond current.

Single-site mean field predicts number states in its Mott lobes and omits finite-J virtual particle–hole fluctuations. Its phase boundaries are approximate; dimensionality, filling, geometry, and correlations matter.

When ψ = 0, order-parameter phase is undefined. Mott clouds therefore use a neutral density color rather than invented random phases. Coherence links display correlations, not particle paths.

J ER ≈ 4π s 34 e −2s U ER ≈ 8π π as a s 34

Here s = V₀ / ER, a is lattice spacing, as / a = 0.02, and ER = ℏ²π² / (2ma²). These are deep-lattice estimates, not an experimental calibration.

Clouds use Gaussian Wannier-like shapes with length ℓ / a = 1 / (πs1/4). Their display size is magnified. Optical oscillations, potential-surface height, and the independent two-site tunneling clock are explanatory displays.

The lowest-band Γ→X cut spans 4J; the full cubic bandwidth is 12J. The momentum diagnostic uses the finite displayed array and the same mean-field coherent fraction, with a Gaussian orbital envelope.
