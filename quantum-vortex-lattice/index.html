Mathematical structure

EXPAND
Density and the order parameter
Ψ= n e iφ n= |Ψ| 2

The complex order parameter encodes condensate number density and phase. Color represents phase; the sampled cloud reveals the density distribution.

Display markers sample a field. Their count is not the number of atoms in an experiment.

Gross–Pitaevskii dynamics
iℏ ∂Ψ ∂t = HGP Ψ
HGP = −(ℏ²/2m)∇² + Vext + g|Ψ|²

Laboratory-frame mean-field dynamics for a dilute, weakly interacting condensate.

This visualization evaluates a prescribed density and phase field. It does not numerically evolve this equation or simulate lattice formation.

Healing length and depleted cores
ξ0 = ℏ 2mg n0

ILLUSTRATIVE CORE FACTOR

f²(s) = s² / (s² + ξ₀²)

s is distance from a vortex axis. This factor suppresses density to zero at the axis and approaches one away from it.

ξ₀ uses the undepleted reference density n₀. The chosen profile is an approximation, and ξ₀ is a reference scale rather than a sharp core boundary.

Phase gradients and superfluid flow
vs = ℏm ∇φ
φ = Σj ℓjθj θj = atan2(−Δzj, Δxj)

The vortex lines point along +y. Each positive winding produces right-handed circulation about that axis. Contributions from neighboring vortices combine.

The velocity relation applies away from density zeros. A uniform phase offset changes the color reference without changing the velocity.

Quantized circulation
ΓC = ∮C vs ·d l = νC κ
κ = h/m ΔφC = 2πνC

νC is the total integer winding enclosed by a contour that avoids zeros of Ψ.

The gold contour encloses one selected ℓ = +1 vortex and excludes its neighbors, so ΓC/κ = +1.

Triangular order and vortex density
Acell = √3 a² / 2 nv = 1/Acell nv ≈ 2Ω/κ

a is the nearest-neighbor spacing. Each triangular lattice site occupies one primitive-cell area.

The Feynman relation connects mean vortex density with bulk rotation. It is a many-vortex approximation; a finite trapped array has edge corrections.

Lattice links are geometric guides. The ordered arrangement is specified rather than formed dynamically.

Rotating coordinates and confinement
Hrot = H − ΩL̂y L̂y = −iℏ(z∂x − x∂z)

For a frame rotating about +y, the Gross–Pitaevskii operator acquires the term −ΩL̂y. The field and coordinates must be interpreted in that frame.

COARSE-GRAINED ENVELOPE

Veff = Vext − ½mΩ²ρ²

Here ρ² = x² + z². This effective potential describes the centrifugal contribution to the bulk envelope. Harmonic radial confinement requires Ω < ω⊥.

Reference scales and model construction
μ₀ = gn₀ τ₀ = mξ₀²/ℏ nbg = max[(μ₀ − Veff)/g, 0] n = nbg ∏j f²(sj)

A Thomas–Fermi background is multiplied by prescribed core-depletion factors. The model uses repulsive contact interactions, g > 0, and straight vortices with ℓj = +1.

The reference healing scale is fixed throughout the display. Boundary corrections, density evolution, and a self-consistent equilibrium solution are not computed.

Playback speed is illustrative. Phase colors, bright axes, and flow markers provide visual measurements of the specified field.
