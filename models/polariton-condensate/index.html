Equations & model scope READ

Three connected representations. The spectrum is analytic. Two spatially uniform population equations are integrated numerically. The spatial profile and coherent phase are prescribed illustrations.

The field is not a solution of a spatial Gross–Pitaevskii equation. The model does not calculate spontaneous coherence, superfluidity, or vortex nucleation.

d nc dτ = (r−1) nc dr dτ = β [ p − ( 1 + nc ) r ]

Phenomenological single-mode populations: nc = RN / γR, r = RNR / γC, τ = γCt, β = γR / γC = 0.35, and p = P / Pth, with Pth = γCγR / R. Here R is the stimulated reservoir-to-mode transfer coefficient.

Initial seed: nc = 10⁻⁴, r = 0. The pump-preparation chapter explicitly restores this seed. Fixed reference rates are independent of detuning; changing composition does not predict an experimental lifetime.

The steady reference is nc,ss = max(p − 1, 0), rss = min(p, 1). Telemetry reports evolving populations, not those steady values.

∫ | uℓ | 2 d2 r = 1

A normalized Gaussian envelope converts mode occupation into a displayed spatial density. An optional vortex adds a normalized depleted core and integer phase winding. Arrows show the prescribed phase gradient, not calibrated velocity.

The lossless coupled-mode gap ΔR / E₀ = 1 is a reference energy. Experimental strong coupling also depends on linewidths. Mirror spacing, layer thickness, electron–hole markers, field height, and optical timing are schematic.

Emission uses Jopt = |C0|²nc, a relative optical proxy with an assumed fixed outcoupling factor. It omits background emission and is not a calibrated detector signal.
